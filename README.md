# TensorHub Technologies plugins for Claude

A Claude Code plugin marketplace from TensorHub Technologies.

| Plugin | What it does |
|---|---|
| [thrivex-live](plugins/thrivex-live) | Ask Claude about your app's users and improve THriveX Live: weekly reviews, help articles from knowledge gaps, setup and IT rollout |

```
/plugin marketplace add TensorHub-Technologies/claude-plugins
/plugin install thrivex-live@tensorhub
```
